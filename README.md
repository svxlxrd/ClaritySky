# Weather REST API (Educational Project)

Этот проект представляет собой RESTful API на языке **Go**, созданный для практики построения надежных микросервисов. Основная цель проекта — изучение и реализация таких важных концепций, как работа с внешними API, механизм повторных запросов (retry) и корректное завершение работы приложения (graceful shutdown).

## 🎯 Цели проекта
- **Практика REST API:** Реализация маршрутизации и обработки HTTP-запросов.
- **Отказоустойчивость:** Реализация механизма **retry** для взаимодействия с внешним API при сетевых сбоях.
- **Graceful Shutdown:** Корректная остановка сервера, обеспечивающая завершение текущих соединений перед выключением приложения.
- **Архитектура:** Использование чистой структуры проекта (разделение на `transport`, `client` и `config`).

## 🛠 Стек технологий
- **Язык:** Go
- **Архитектура:** `net/http` (стандартная библиотека)
- **API Провайдер:** [Open-Meteo](https://open-meteo.com/)
- **Инструменты:** Контексты, сигналы ОС, управление таймаутами.

## 🚀 Основные возможности
- Получение текущих погодных данных по параметру города.
- Автоматические повторные попытки (retry) при неудачных запросах к внешнему провайдеру.
- Безопасное завершение работы сервера по сигналу `SIGINT` / `SIGTERM`.
- Гибкая настройка через конфигурационные файлы (таймауты чтения/записи/ожидания).
